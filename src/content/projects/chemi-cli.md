# Smart Irrigation System

This project aims to reduce water waste in urban gardening by using soil moisture sensors and weather data to automate watering schedules.

## Features
- Real-time soil moisture monitoring
- Weather forecast integration
- Remote control via mobile app
- Low-power consumption
